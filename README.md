# Edge Trainer — Blackjack

Full advantage play curriculum: basic strategy, Hi-Lo counting, true count, deviations, paper trading, and gamified XP progression.

## Deploy to your phone in 5 steps

### Step 1: Upload to GitHub
1. Go to github.com and log in
2. Click the **+** icon → **New repository**
3. Name it `edge-trainer`, set to Public, click **Create repository**
4. Click **uploading an existing file**
5. Drag and drop ALL the files from this folder (including the `src/` and `public/` folders)
6. Click **Commit changes**

### Step 2: Deploy on Vercel (free)
1. Go to vercel.com → Sign up with GitHub
2. Click **Add New Project**
3. Select your `edge-trainer` repository
4. Leave all settings as default — Vercel auto-detects Vite
5. Click **Deploy** — takes about 60 seconds
6. You'll get a URL like `edge-trainer-xyz.vercel.app`

### Step 3: Add to your iPhone home screen
1. Open the Vercel URL in **Safari** (must be Safari on iPhone)
2. Tap the **Share** button (box with arrow)
3. Tap **Add to Home Screen**
4. Tap **Add**
5. The app icon now lives on your home screen — opens fullscreen, works offline

### Step 4: Add to Android home screen
1. Open the Vercel URL in **Chrome**
2. Tap the **three dots** menu
3. Tap **Add to Home Screen**
4. Tap **Add**

---

Your progress (XP, streak, nemesis hands) saves locally on each device.
